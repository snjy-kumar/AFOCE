# Security Policy

## Reporting a vulnerability

If you find a security issue, do not open a public issue.

Use GitHub Private Vulnerability Reporting for this repository, or contact maintainers privately with:

- Impact summary
- Steps to reproduce
- Suggested fix (if available)

## Response expectations

- Initial triage acknowledgement target: within 72 hours.
- Confirmed vulnerabilities are prioritized over feature work.

## Supported versions

Security fixes are applied to the active mainline branch first.

## Security requirements for contributors

- Do not commit credentials, tokens, or secrets.
- Do not weaken auth or RLS protections.
- Do not add fail-open behavior for security checks.
